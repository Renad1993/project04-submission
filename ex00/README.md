# Personal Portfolio

This project is a personal portfolio website created using HTML, CSS, and JavaScript.

## Features

- About Me section
- Skills section
- Projects showcase
- Hobbies section
- Contact form
- Light and dark theme switcher
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Git

## How to Run

Open the `index.html` file in a web browser.
